# Seven motions

An original seven-room film gallery: **a seed travels across the world**.

Live: https://raj-microsoft.github.io/seven-motions/

Method credit: **Janus Tiu — Claude Opus 5.5 Motion Videos Tutorial**, [original guide in the public design library](https://raj-microsoft.github.io/ai-web-design-library/assets/janustiu-claude-motion-videos-tutorial.pdf). No source PDF or source frames are redistributed here.

## What's here
- Seven self-contained Canvas HTML films, `films/<style>/index.html`. Each exposes `seek(t)` after `window.ready`.
- Seven 1080×1920, 30 fps H.264/AAC MP4s, eight or nine seconds each, below 8 MB each.
- Original poster images and post-render four-key contact sheets.
- A responsive gallery with offscreen pause, reduced-motion posters, playback/scrubbing and opt-in sound.
- Original synthesized music and effects, loudness-normalized toward −14 LUFS.

The paid Claude Code / Opus 5.5 workflow is substituted with local code authoring, Canvas, Python, Playwright and ffmpeg. Ink is an analytic deterministic curl-flow approximation, not a physical fluid solver. Guide palettes and movement grammar are retained while the subject and final words are adapted to the seed. Typography, the flying machine and paper craft are code-generated interpretations rather than photographed material. Short films restart visibly; they are not seamless loops.

## Rebuild
Requirements: Python 3.12+, `pip install pillow playwright`, ffmpeg/ffprobe, installed Microsoft Edge (edit `EDGE` in scripts on other platforms).

```
python tools/build.py
python tools/render.py
python tools/verify.py
```

Serve the repository as static files. No build-time secrets, runtime accounts, paid APIs or external font requests. `tools/build.py` embeds the shared renderer and Anton into each standalone film. The gallery itself plays the compact MP4s to keep mobile CPU use low; inspecting a film opens the seekable code-driven source frame.

## Provenance
All films, posters and contact sheets are generated from `tools/motion.js` and seeded constants. Audio is synthesized in `tools/render.py`. Pre-build PNG storyboards are generated by `storyboard/make_storyboards.py`; review was approved by the coordinating session before film implementation. Risograph was revised into distinct arrival, boat, sea, accordion-landscape and rooting scenes after review. No third-party photos, motion frames or audio samples are used. Anton by Vernon Adams is distributed under the SIL OFL in `assets/OFL-Anton.txt`.

## Verification
Deterministic seek (seek 3 → seek 1 → seek 3, identical pixels), seven video/audio streams, duration/size/dimensions/frame rate, responsive 1440/390 widths, no horizontal overflow, reduced-motion pause, play/pause and sound controls, and browser error checks. Original contact sheets and local screenshots visually reviewed. Impeccable detector: no findings after correcting small text; explicit waiver only for guide-required graph-paper cream palette.
